# Merchant security

Merchant account owners can enable or disable email two-factor authentication from their profile settings. When enabled, dashboard sign-in requires an email verification code after password validation.

IP allowlisting restricts external merchant API key authentication to the merchant's configured IP addresses. Changes to the list take effect on subsequent token requests.
